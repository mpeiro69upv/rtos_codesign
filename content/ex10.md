title: "10. Flags de Eventos"

En este ejercicio queremos escribir un mensaje por la pantalla en caso de que sucedan varias cosas (eventos).

### Objetivo

Por ejemplo:
- Mediante texto por teclado PS2 se ha introducido el código correcto
- Se ha pulsado KEY1
- El SW8 está a '1'

**No importa el orden** en el que ocurran los eventos previos, lo importante es que "en caso de que ocurran los 3 eventos" se debe mostrar un mensaje por la pantalla que diga:

> **"¡Código Correcto y KEY1 pulsado y SW8 activo... volvamos a empezar!"**

Puede incluir algún mensaje adicional, por ejemplo, indicando el número de intentos que ha utilizado para descubrir el código.

Debe desactivarse el flag de eventos una vez que los tres eventos se cumplan, de forma que estemos preparados para empezar otra vez.

> **Nota**: Medite unos minutos sobre la construcción del ejercicio y debata con el profesor.

### Implementación de la solución

#### Tarea de verificación de eventos (TaskFlags)

Creamos una tarea que verifique cada segundo (por ejemplo) que los 3 eventos han ocurrido (`TaskFlags`).

<br>

## Tarea de verifica (Pend) que han ocurrido los eventos (flags) deseados
```c
#include "..\inc\taskflags.h"

void TaskFlags()
{

  char texto[80];

  while(1)
  {
  
    OSSemPend(Semaphore,0,&error);
    alt_ucosii_check_return_code(error);
    printf("Hello from TaskFlags\n");
    OSSemPost(Semaphore);

    OSTimeDlyHMSM(0,0,1,0); // Delay for 1 seconds
    
    FlagQuery = OSFlagAccept(EventFlag,0x07,OS_FLAG_WAIT_SET_ALL, &error);
    //alt_ucosii_check_return_code(error);
    OSSemPend(Semaphore,0,&error);
    alt_ucosii_check_return_code(error);
    printf("Flags status is %x\n", (int)FlagQuery);    
    OSSemPost(Semaphore);
    

    if(FlagQuery == 0x07)
    {
      sprintf(texto, "Codigo Correcto y KEY1 pulsado y SW8 activo... volvamos a empezar!");
      
      // Clear all flags
      OSFlagPost(EventFlag,0x07,OS_FLAG_CLR, &error);
      alt_ucosii_check_return_code(error);
    } else {
      sprintf(texto,"Valor de los flags es %x", (int)FlagQuery);
    }
    OSSemPend(Semaphore,0,&error);
    alt_ucosii_check_return_code(error);

    VGA_Clean_Full_Lines(50,52,character_buffer);
    VGA_text(10,50,texto,character_buffer);

    OSSemPost(Semaphore);
    
    
  }
}
```

Se observa:
- Cada segundo se verifica un flag de eventos y se chequean los bits 1, 2 y 3 con valor "1"
- No se espera de forma bloqueante, de esta forma se puede mostrar un mensaje por la pantalla cada segundo
- Si los tres flags están a "1" se prepara mensaje de éxito y se ponen a "0" con un post
- Si aún no están activos se prepara un mensaje de información
- Se muestra el mensaje por la pantalla

### Activación de los flags

Para activar los flags, se debe pensar que:

#### En TaskSW (para SW8) - descomente las lineas indicadas -

```c
// when SW8 is ON activates Flag
if ((*SW_switch_ptr>>8)){
    OSFlagPost(EventFlag,0x04,OS_FLAG_SET,&error);
    alt_ucosii_check_return_code(error);
}else{
    OSFlagPost(EventFlag,0x04,OS_FLAG_CLR,&error);
    alt_ucosii_check_return_code(error);
}
```

#### En ISR de pulsadores (para KEY1):

```c
//when KEY1 is pressed activates Flag
case 0x2:{
    OSFlagPost(EventFlag,0x01,OS_FLAG_SET,&error);
    alt_ucosii_check_return_code(error);
}
break;
```

#### En TaskCode (para código correcto del teclado):

**Cuando es código correcto:**
```c
// if Code is correct activates flag
OSFlagPost(EventFlag,0x02,OS_FLAG_SET,&error);
alt_ucosii_check_return_code(error);
```

**Cuando es código incorrecto:**
```c
// if Code is not correct deactivates flag
OSFlagPost(EventFlag,0x02,OS_FLAG_CLR,&error);
alt_ucosii_check_return_code(error);
```

### Creación del flag de eventos

Por último, recuerde que el flag de eventos debe crearse, necesitando:

```c
OS_FLAG_GRP* EventFlag;
EventFlag = OSFlagCreate(0x00,&error);
alt_ucosii_check_return_code(error);
```
